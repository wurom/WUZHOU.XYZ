主要功能
⏰

时钟与万年历

公历 + 农历 + 干支 + 二十四节气 + 节日，全部本地计算不联网。外部 32.768 kHz 晶振走时，连接态 / 断开态两套折算系数分别标定，另带 ±500 ppm 微调。

🗓️

倒计时与重要日

高考日期与「重要日」都能由上位机写入，掉电不丢；时钟页底部常驻一条天数提示，倒计时页整屏放大显示。

📷

手机推图

Web 蓝牙推送任意 1bpp 位图，支持 RAW / RLE / XOR-RLE 三种编码，边收边解不占内存，CRC32 不符不会把半张图刷上屏。

🚗

挪车联系

号码可随时用手机改写、屏上即时预览，可选择掉电持久化。输入可以带空格、横线、括号，设备统一归一化；没写号码就显示「号码未设置」。

🔄

双 bank 差分 OTA

只写非运行中的 bank，按 4 KB 扇区位图差分传输，未改动的扇区在设备本地复制不过射频。COMMIT 前不改目标 bank 头，中途断电仍启动旧固件。

🎛️

显示选项

反色、月历网格、12 / 24 小时制、七段数码管字体四项开关，写入后掉电保留；网页连上会回读设备真实状态，不会「网页勾着、屏上另一种」。

💾

掉电保存

当前页面、重要日、显示选项、挪车号码、走时系数与时区分别落在独立记录扇区，各自带 CRC 校验（走时记录三份冗余），升级回退也不丢校准。

🩺

自诊断

硬件看门狗防卡死，复位归因黑匣子区分「主动复位 / 看门狗 / 断电」，接线自检位一眼看出哪项功能没接上，日志事件从状态通道实时上报。

三分钟上手
1

连上设备

用 Chrome / Edge 打开网页工具，点「连接」选中 WZHM213_XXXX。无需安装 App、无需注册。

2

对时

点「对时」写入当前时间；勾选「自动校正走时误差」后，工具会静置采样并用回归算出本机系数写回设备。

3

选页 / 推图 / 升级

六个功能页一键切换；图片页推 1bpp 位图；OTA 页选固件包即可在线升级，失败可回退。

Web Bluetooth 需要 Chrome、Edge 或安卓 Chrome；iOS / Safari 不支持，请用安卓手机或电脑操作。 OTA 期间请勿断电——即便断电，设备也只会继续运行旧固件。
