使用与限制

  • 需 Chrome / Edge 桌面版，且通过 localhost 或 HTTPS 打开。
  • Web Bluetooth 不暴露 MTU；包长会在写入失败时自动降级 244 → 182 → 20。
  • DA14585 不支持 2M PHY，射频层只有 1M PHY + DLE 一条提速路径。
  • 要跑满 244 B/包，中央设备与系统蓝牙栈都必须支持 DLE。
  • 图片通道的端到端延迟主要来自 EPD 全刷 1~3 秒，不在空口。
  • 固件侧仍需实现 platform.h 回调、屏驱动初始化序列与 LUT。
